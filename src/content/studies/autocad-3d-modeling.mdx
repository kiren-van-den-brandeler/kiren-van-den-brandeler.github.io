## AutoCAD 3D Model: Cylinder, Conrod Bushes, and Piston

This study aggregates three concise AutoCAD tutorials that demonstrate building common engine components from 2D sketches into accurate 3D solids. Each episode focuses on core commands, practical modeling patterns, and manufacturing-aware choices.

---

### Episode 01 — Cylinder & Connecting Rod

Summary: Convert precise 2D profiles into solid geometry using EXTRUDE for prismatic features and REVOLVE for axisymmetric elements. Use boolean UNION and SUBTRACT operations for mating features, and finish with FILLET/CHAMFER and dimension constraints to ensure fit and clearance.

### Episode 02 — Conrod Bushes

Summary: Model multi-diameter bush assemblies by stacking revolved sections and using polar arrays to create repeated oil passages. Emphasizes workplane setup, consistent layering, and preparing parts for manufacturing (clearances, bolt/flange features).

---

### Episode 03 — Piston

Summary: Sketch the piston cross-section and use REVOLVE to create the main body, then add ring grooves, pin bores, and fillets. Shows techniques for patterned features and considerations for tolerance and ring clearance.

## Key Takeaways

- Core commands: REVOLVE, EXTRUDE, UNION, SUBTRACT, FILLET, CHAMFER, POLAR ARRAY
- Workflow: accurate 2D sketch → choose revolve vs extrude → build features with boolean ops → finish and validate fit
